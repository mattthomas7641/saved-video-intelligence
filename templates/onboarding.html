Import your Saved videos

TikTok doesn't offer an API for reading your Saved/Favorites list, so the reliable (and ToS-friendly) way in is your own official data export.

1. Request your data from TikTok

  1. Open the TikTok app → Profile → Menu (☰) → Settings and privacy
  2. Go to Account → Download your data
  3. Request a file in JSON format (not TXT — JSON keeps the save dates)
  4. TikTok takes anywhere from a few minutes to a few days to prepare it — you'll get a notification when it's ready
  5. Download the .zip and unzip it; look for a file like user_data_tiktok.json

2. Upload it here

This file never leaves your machine except for the short transcript/caption text sent to Claude for summarization once you start processing.
