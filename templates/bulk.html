Keeping it running

  • Leave Docker Desktop open. If your Mac sleeps, the work pauses and picks up again when it wakes.
  • To keep the Mac awake for a long run, open Terminal and run this, leaving the window open:
    caffeinate -dims
  • Everything is saved as it goes. Stopping, restarting or a crash loses at most the videos in progress.
  • The newest saves are processed first, so a partial run covers what you saved most recently.
