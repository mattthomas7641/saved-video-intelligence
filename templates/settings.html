Send to Sidequest

{% if ntfy.inbox_topic %}{{ icon("check") }} Set up {% else %}{{ icon("alert") }} Not set up{% endif %}

From TikTok, Instagram, YouTube, Safari, Photos or a fresh screenshot: Share → Send to Sidequest. Videos, links, screenshots and text all work. They go through a private relay (ntfy.sh, free), this app picks them up, and the result comes back as a phone notification. Nothing on this computer is exposed to the internet.

{% if not ntfy.inbox_topic %}
{% else %}
  1. On your iPhone, install the free ntfy app, tap + and subscribe to: {{ ntfy.results_topic }}
  2. Open Shortcuts → + → name it Send to Sidequest. Tap ⓘ, turn on Show in Share Sheet, and set it to receive URLs, Text and Images.
  3. Add If: Shortcut Input is Image (tap the input to pick its type).
  4. Inside the If, for screenshots and photos:
    • Convert Image Shortcut Input to JPEG
    • Get Contents of URL: URL {{ ntfy.server }}/{{ ntfy.inbox_topic }}, Method PUT, Request Body File = Converted Image
    • Add two headers: Filename = shot.jpg, and Message = {"v":1,"token":"{{ ntfy.token }}"}
  5. In Otherwise, for links and text:
    • Get Contents of URL: same URL, Method POST, Request Body JSON with three fields:
    • v (Number) = 1, token (Text) = {{ ntfy.token }}, url (Text) = Shortcut Input
  6. After End If, optionally add Show Notification “Sent to agent”. The first time you share from TikTok or Instagram, tap More → Edit Actions and add Send to Sidequest to Favorites so it sits at the top.
